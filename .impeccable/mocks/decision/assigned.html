(57) Brings a change's specs and design up to date with what was actually built, before archive.

1.Docs sync sources

The docs sync runs as part of the verify step for one change. It gathers the decisions the build recorded, the commits since the change's artifacts were last edited, the change's diff, and the dependencies added or removed.

wherein, docs stopped early:
GIVENa change whose design and specs were last committed on 2026-10-10, followed by 29 code commits
WHENthe docs sync runs
THENit reports “docs last updated 2026-10-10; 29 code commits since”

2.Sort what was built

Each item found is sorted into a behavior, a decision with depth, or how the build ran.

Description · why

The apply receipt is overwritten on every iteration, so the build's rulings vanish unless the sync moves them into the specs before archive.

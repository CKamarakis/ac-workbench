## REMOVED Requirements

### Requirement: Offer to update a matching PRD after capture
**Reason**: capture only saves the note (flexible-handoffs). The user decides when a PRD takes in new notes: an offer after every note was an interruption, and noisy when one note touches several PRDs.
**Migration**: the user asks `/kit:prd` to update a PRD from their notes (per-section update, unchanged); a notes service is a v2 roadmap item.
